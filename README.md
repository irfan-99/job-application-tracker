Job Application Tracker

A beginner-friendly web application for managing job applications through different recruitment stages.

Features

- Add job applications with company name, role, date and status
- Edit and delete applications
- Search by company or job role
- Filter applications by status
- View total applications, interviews and selections
- Save application data using browser LocalStorage
- Responsive interface with CSS animations and hover effects

Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Browser LocalStorage

How to Run

1. Clone or download this repository.
2. Open "index.html" in a web browser.
3. Add and manage your job applications.

Learning Objectives

This project demonstrates DOM manipulation, JavaScript arrays and objects, event handling, filtering, CRUD operations and browser-based data persistence.

Limitations

Data is stored locally in the current browser. It is not synchronised between devices and does not use a backend database.

Future Improvements
